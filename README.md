# Smart Parking System 🚗🅿️

A Full-Stack MERN project created for our final year computer science coursework. 

This application helps drivers find and reserve nearby parking spots easily, while allowing parking space owners to list their available spaces and manage bookings in real time.

---

## 📌 Project Features

### 👤 User (Driver) Features
- **Search Nearby Parking**: Find nearby parking spots based on your location using interactive maps.
- **Slot Booking**: Reserve parking slots for specific dates and times.
- **AI Spot Availability Predictor**: Predicts whether parking slots are likely to be available or full.
- **Peak Hour Analytics**: Shows busy hours so users can plan ahead.
- **AI Chatbot**: Built-in assistant to help find budget-friendly parking options.
- **My Bookings**: View current and past booking history.

### 🅿️ Owner Features
- **Add Parking Spots**: List new parking locations with slot numbers, hourly prices, and location coordinates.
- **Manage Booking Requests**: Approve or reject user reservation requests.
- **Owner Dashboard**: Track active bookings and total earnings.

### 🛡️ Admin Features
- **Approve Parking Spaces**: Verify and approve newly added parking locations before they go public.
- **User Management**: View and manage registered users and space owners.

---

## 🛠️ Tech Stack Used

- **Frontend**: React.js, React Router, Leaflet Maps, Google Maps API, Axios, CSS3
- **Backend**: Node.js, Express.js, JWT (JSON Web Tokens), Bcryptjs
- **Database**: MongoDB Atlas
- **Hosting / Deployment**: Vercel (Frontend), Render (Backend API)

## ⚙️ How to Run Locally

### 1. Clone the Project
```bash
git clone https://github.com/Thejasrini/Smart-Parking-System.git
cd Smart-Parking-System
```

### 2. Setup & Run Backend
```bash
cd backend
npm install
npm run dev
```
*(Backend runs on `http://localhost:5000`)*

### 3. Setup & Run Frontend
Open a new terminal:
```bash
cd frontend
npm install
npm start
```
*(Frontend runs on `http://localhost:3000`)*
